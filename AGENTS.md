# AGENT RULES & INSTRUCTIONS

## 1. Aturan Dasar (Anti-Slop)

- Langsung berikan kode utuh tanpa basa-basi pembuka/penutup.
- DILARANG menggunakan komentar AI slop yang tidak perlu.
- Terapkan prinsip YAGNI (HANYA ubah file yang relevan).

## 2. Modul Aturan Spesifik (BACA SAAT TERKAIT)

Sebelum membuat atau mengubah kode, WAJIB membaca file aturan modular berikut yang ada di dalam folder `.kilo/`:

- **Vue 3 SFC:** Jika membuat atau mengedit komponen `.vue`, BACA `.kilo/rules/vue.md`.
- **daisyUI & Styling:** Jika membuat layout, form, atau komponen UI, BACA `.kilo/rules/daisyui.md`.
- **State & API (opsional):** Jika mengelola Pinia store atau fetching API, BACA `.kilo/rules/api.md`.

## 3. Eksekusi

- Pastikan kode yang dihasilkan sesuai dengan standar pada file aturan modular di atas.
